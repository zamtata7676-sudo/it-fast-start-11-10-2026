Main git commands

  • git status - команда, яка відображає поточний стан
  • git branch - команда, яка відображає список гілок в репозиторії
  • git add - команда, яка відображає відмінності за внесеними змінами у ще не проіндексованих файлах
  • git push - команда, яка завантажує всі зміни локальної гілки у віддалений репозиторій
  • git commit -m - команда, яка фіксує проіндексовані зміни та зберігає їх в історію версій
  • git checkout b - команда, яка перемикається на вибрану гілку та оновлює робочу директорію до її стану
